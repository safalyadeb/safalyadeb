## About Me

Hi, I'm **Safalya Deb Biswas**, a Computer Science & Technology diploma student from **West Bengal, India**, working towards becoming a capable Full-Stack Developer.

I'm interested in how thoughtful user interfaces, reliable backend systems, and well-structured data come together to solve real problems. I enjoy turning ideas into practical web applications and strengthening my fundamentals through hands-on building.

- Studying **Computer Science & Technology**.
- Exploring both **frontend and backend** web development.
- Building with JavaScript and the modern web ecosystem.
- Learning through projects, experimentation, and iteration.
- Focused on writing cleaner code and improving my problem-solving skills.

I'm at the learning-and-building stage of my journey, and I value consistent progress over inflated titles.
